# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search and delete notes. Notes can be assigned to Personal, Work or Study categories, and they are automatically saved in the browser so they remain available after refreshing the page.

## Features

- Add new notes
- Choose a category for each note
- Personal, Work and Study categories
- Delete individual notes
- Search notes in real time
- Case-insensitive search
- Validation for empty notes
- 200-character limit
- Note count display
- Displays the date and time each note was created
- Saves notes using localStorage
- Responsive layout for smaller screens
