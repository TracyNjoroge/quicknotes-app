# 📝 QuickNotes

QuickNotes is a simple note-taking web application that lets users create, organize, search and delete notes. Notes can be assigned to Personal, Work or Study categories and are saved automatically in the browser, so they are still there after a page refresh.


## Features

- Add notes and assign a category (Personal, Work or Study)
- Delete individual notes
- Real-time, case-insensitive search
- Validation for empty notes and a 200-character limit
- Note count display
- Date and time shown for each note
- Notes saved with `localStorage`
- Responsive layout for smaller screens


## Built With

HTML, CSS and vanilla JavaScript


## How to Run Locally

1. Clone the repository:

```bash
   git clone https://github.com/<your-username>/quicknotes-app.git
   cd quicknotes-app
```

2. Open `index.html` in your browser.

No installation or build step is needed.
